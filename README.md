##  프로젝트 한눈에 보기
Lofi Room은 집중과 휴식을 위한 올인원 데스크탑 앱입니다.  
포모도로 타이머, Todo 리스트, 음악 플레이어를 위젯 형태로 제공하며,  
사용자는 자신의 작업 환경에 맞게 배치하고 테마(라이트/다크 모드)를 전환할 수 있습니다.

---
> **Stack:** C#, WPF, SQLite   

## 주요 기능

###  포모도로 타이머
- 25분 집중 + 5분 휴식 주기
- 원형 프로그레스 링 애니메이션
###  Todo 리스트
- 할 일 추가 / 완료 / 삭제
-  SQLite 기반 저장
###  위젯 시스템
- 드래그 & 드롭으로 자유 배치
- 스티커노트처럼 여러 위젯을 조합 가능
###  테마 전환
- 라이트/다크 모드 지원
- 버튼 클릭으로 즉시 전환
- 위젯 색상도 함께 변경

---
## 개발환경
- DB: SQLite
- GUI: WPF (C#)
- OS: Windows 10
- IDE: Visual Studio 2022
